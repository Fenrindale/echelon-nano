역할 경계

  • Analyst — 등록된 정보의 검색과 관리
  • Handler — 계획과 Agent 지휘
  • Agent — Work Order 범위의 실행
  • Master — 감사와 지식 최적화
이 버전은 인증과 권한을 검증하는 기반입니다. 일반 업무 도구와 전체 UI는 후속 단계입니다.
